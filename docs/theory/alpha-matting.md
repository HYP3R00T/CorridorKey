# Alpha Matting

## What an alpha matte is

An alpha matte is a grayscale image where each pixel value represents opacity. White (1.0) means fully opaque foreground. Black (0.0) means fully transparent background. Values in between represent partial transparency — the soft edges of hair, motion blur, or translucent fabric.

In compositing, the alpha matte is multiplied against the foreground colour to produce a premultiplied RGBA image. Transparent regions are zeroed out, so the foreground can be placed over any background without colour contamination.

## The AlphaHint

CorridorKey requires an alpha hint for each clip. The hint is a coarse, approximate matte — it does not need to be production quality. Its purpose is to tell the model roughly where the subject is so the model can focus its refinement on the right regions.

A typical alpha hint is generated by:

- A fast chroma keyer (Primatte, Keylight, a simple threshold)
- A rotoscoping tool
- Another AI model trained for coarse segmentation

The hint is stored in the `AlphaHint/` folder alongside the input frames. If no hint is present, CorridorKey cannot proceed without an `AlphaGenerator` plugin that generates one automatically.

## How the hint is used

The preprocessor stacks the source frame and the alpha hint into a 4-channel tensor (RGBA) and passes it to the model. The model uses the hint channel as a spatial prior — it knows which regions are likely foreground and which are likely background — and produces a refined matte that respects fine edge detail the hint missed.

After inference, the `hint_sharpen` postprocessing step uses the binarised hint to remove soft tails introduced by upscaling. This keeps the final matte clean in regions where the hint is confident, while preserving the model's soft edge detail where the hint is uncertain.

## Premultiplied vs straight alpha

CorridorKey writes two foreground outputs:

- `fg/` — straight alpha foreground. The colour values are not multiplied by alpha. Use this when your compositor expects straight alpha.
- `processed/` — premultiplied RGBA. The colour values are multiplied by alpha, and transparent regions are zeroed out. This is the primary compositor output and the correct format for most compositing workflows.
